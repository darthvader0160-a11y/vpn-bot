# VPN-бот: ключи для V2Box

Свой VPN на зарубежном сервере и Telegram-бот, который выдаёт ключи. Человек жмёт «Запросить доступ», ты одобряешь, бот присылает ссылку-подписку и QR-код. Ссылку человек добавляет в **V2Box** (iPhone, Android, Mac).

**Как устроено**
- На сервере работают панель **3x-ui** (внутри Xray) и бот. Оба ставятся одной командой.
- В подписке два подключения:
  - **Основной**: VLESS + Reality + XHTTP, порт 443. На 2026 год его ТСПУ блокирует реже всего.
  - **Резервный**: VLESS + Reality + Vision, порт 8443.
  Для ТСПУ трафик выглядит как обращение к обычному сайту (по умолчанию `www.samsung.com`).
- Подписка обновляется сама раз в 12 часов. Если поменять протокол или маскировку, людям ничего не надо переустанавливать.
- Панель из интернета не видна, зайти в неё можно только через SSH. Открытый вход в панель выдаёт VPN-сервер, поэтому его закрыли.
- Лимит — 50 человек, настраивается.

---

## 1. Купить сервер (≈10 минут)

| Что | Значение |
|---|---|
| Где | **4VPS** (4vps.su) или **Timeweb Cloud** (timeweb.cloud). У обоих оплата СБП или картой МИР |
| Страна | **Нидерланды** или **Финляндия** (Германия тоже подойдёт). **Не Россия** |
| Система | **Ubuntu 24.04** |
| Мощность | 2 ядра, 2 ГБ памяти, диск от 20 ГБ. На 50 человек хватает с запасом |
| Трафик | безлимит или от 2 ТБ в месяц, канал 1 Гбит/с |
| Цена | ориентир 400–900 ₽ в месяц |

После оплаты хостер пришлёт **IP-адрес** и **пароль root**. Сохрани их.

> Hetzner, DigitalOcean и Aeza не бери: их подсети чаще других попадают под блокировки РКН, а Aeza ещё и под санкциями США.

## 2. Создать бота (2 минуты)
1. В Telegram открой **@BotFather** → `/newbot` → придумай имя и юзернейм. Сохрани **токен**.
2. Открой **@userinfobot** и сохрани свой **ID** (только цифры).

## 3. Установить на сервер (≈10 минут)
На Mac открой программу **Терминал**.

1. Отправь папку бота на сервер. Вместо `IP` подставь адрес сервера, вместо пути — где у тебя лежит папка `bots`:
   ```
   scp -r ~/Desktop/bots/vpn-bot root@IP:/opt/
   ```
   На вопрос `Are you sure…` напиши `yes`, потом введи пароль root. Символы пароля при вводе не видны, так и должно быть.
2. Зайди на сервер и запусти установку:
   ```
   ssh root@IP
   bash /opt/vpn-bot/install.sh
   ```
3. Скрипт спросит **токен бота** и твой **Telegram ID**. Дальше он всё сделает сам: Docker, файрвол, ускорение BBR, панель, ключи Reality, бот.
4. В конце скрипт покажет доступы к панели. Они же лежат в файле `/opt/vpn-bot/ДОСТУПЫ.txt`.

## 4. Проверить
1. Напиши своему боту `/start`. Тебе, как админу, ключ придёт сразу.
2. Поставь **V2Box**: [App Store](https://apps.apple.com/app/id6446814690) · [Google Play](https://play.google.com/store/apps/details?id=dev.hexasoftware.v2box).
3. Коснись ссылки в сообщении бота, она скопируется. В V2Box: **Configs → «+» → Add subscription** → вставь ссылку → Save.
4. Выбери **Основной** → **Home → Connect**. Открой любой заблокированный сайт.

## 5. Пускать людей
- **По заявке.** Человек находит бота и жмёт «Запросить доступ». Тебе приходит заявка с кнопками ✅ / ❌.
- **По приглашению.** «⚙️ Админка → 🎟 Приглашение» создаёт одноразовую ссылку. Перешли её человеку, и ключ выдастся сразу, без заявки.

## Админка в боте (кнопка «⚙️ Админка»)
| Кнопка | Что делает |
|---|---|
| 👥 Пользователи | Список. В карточке человека: трафик, ⏸ пауза / ▶️ включить, 🔄 новый ключ (если ключ утёк), 🗑 удалить (место освобождается) |
| 📨 Заявки | Необработанные заявки |
| 🎟 Приглашение | Одноразовая ссылка с доступом без заявки |
| 📣 Рассылка | Сообщение всем активным пользователям |
| 🖥 Сервер | Работает ли Xray, загрузка процессора и памяти, сколько человек онлайн |

У пользователей есть кнопки «🔑 Мой ключ», «📖 Как подключить», «📊 Мой трафик» и «🆘 Не работает». Последняя присылает тебе сигнал.

## Панель 3x-ui (если нужно)
Через панель можно поменять маскировку, порты и посмотреть подробную статистику. Бот работает и без неё.
1. В Терминале на Mac: `ssh -L 8080:127.0.0.1:ПОРТ root@IP` (точная команда есть в `ДОСТУПЫ.txt`).
2. Не закрывая Терминал, открой в браузере ссылку из `ДОСТУПЫ.txt`.

Подключения бота называются `vpn-xhttp` и `vpn-tcp`. **Не удаляй их и не переименовывай.** Клиентов `uNNN-…` тоже не трогай руками: ими управляет бот.

## Если VPN начали блокировать
1. **Сменить маскировку.** В панели открой подключение → Reality → поле *Target / SNI*. Подбери сайт, который хостится рядом с твоим сервером (в панели есть кнопка сканирования). Сохрани и перезапусти бота (команда ниже). Ссылки в подписке обновятся у всех сами.
2. **Сменить сервер.** Купи новый, перенеси папку `/opt/vpn-bot` целиком (`data` и `xui-db` — это пользователи и ключи) и запусти `install.sh`. У нового сервера другой IP, поэтому через «📣 Рассылку» попроси всех нажать «🔑 Мой ключ» и добавить подписку заново.
3. **Белые списки на мобильном интернете** обходит только «мост» через российский сервер. Это второй этап, бот к нему готов.

## Обслуживание (команды на сервере)
```
cd /opt/vpn-bot
docker compose ps                    # всё ли запущено
docker compose logs --tail 50 bot    # журнал бота
docker compose restart bot           # перезапустить бота
docker compose up -d --build         # обновить после изменений в коде
```
**Резервная копия** — папки `/opt/vpn-bot/data` и `/opt/vpn-bot/xui-db`. Скачать на Mac:
`scp -r root@IP:/opt/vpn-bot/data root@IP:/opt/vpn-bot/xui-db ~/Desktop/vpn-backup/`

## Настройки (`/opt/vpn-bot/.env`)
| Переменная | Что это |
|---|---|
| `BRAND` | Название сервиса в V2Box и в боте |
| `SERVER_NAME` | Подпись сервера, например `🇫🇮 Финляндия` |
| `MAX_USERS` | Лимит пользователей (по умолчанию 50) |
| `ADMIN_IDS` | ID админов через запятую |
| `REALITY_SNI` | Сайт для маскировки. Работает только при первой установке, потом меняется в панели |

После правки: `docker compose up -d`.

## Для разработчика
- Код: `bot/` (Python 3.13, aiogram 3). API панели — `bot/panel.py`, подключения и ссылки — `bot/vpn.py`, раздача подписок — `bot/subserver.py`, тексты — `bot/texts.py`.
- Тесты с имитацией API 3x-ui и Telegram: `python -m unittest discover -s tests`.
- Версия панели закреплена в `docker-compose.yml` (3.11.0). Перед обновлением панели прогони бота на тестовом сервере.
